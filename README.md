
# 🎨 colorGame

Prosta i wciągająca gra zręcznościowa stworzona w języku **C#** , w której kluczem do sukcesu jest spostrzegawczość i szybka reakcja na kolory.

---

## 🕹️ O grze
W **colorGame** Twoim zadaniem jest poruszanie się postacią zgodnie z wyświetlanymi kolorami. Gra sprawdza, jak szybko potrafisz dopasować swój ruch do zmieniającego się otoczenia.

## 🚀 Funkcje
* **Dynamiczna rozgrywka:** Kolory zmieniają się w trakcie gry.
* **Intuicyjne sterowanie:** Proste zasady, które zrozumiesz w sekundę.

## 🛠️ Technologie
* **Język:** C#
* **Środowisko:** Visual Studio

## 📥 Jak uruchomić
1. Pobierz repozytorium (Download ZIP) lub sklonuj je za pomocą Gita.
2. Otwórz plik `colorGame.sln` w programie **Visual Studio**.
3. Naciśnij `F5` lub przycisk **Start**, aby skompilować i uruchomić grę.
